You must first build the main UnleashedRecomp project in cmake, then copy the following artifacts:

## DLLs
Place DLLs under `deps/bin`

- D3D12/D3D12Core.dll
- D3D12/d3d12SDKLayers.dll
- dxcompiler.dll
- dxil.dll
- libuwp.dll (If updated)
- UnleashedRecomp.dll

## Libs
Place libs under `deps/lib`

- UnleashedRecomp.lib
